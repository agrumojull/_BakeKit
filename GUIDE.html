🍰 BakeKit

Bake d'éclairage réaliste (GI, ombres, AO) sur un modèle 3D — sans jamais ouvrir Blender à la main.

🚀 Commande de base

bakekit mesh.glb

Produit une texture combined (couleur + lumière) prête à charger dans Three.js, dans un dossier ./out à côté du fichier.

Le mesh doit avoir des UVs (dépliage 0–1), et une source de lumière (voir ci-dessous).

📍 Installer la commande & chemins des .glb

La commande bakekit n'est pas installée globalement par défaut. À faire une seule fois :

cd C:\...\BakeKit
npm link

Ensuite, bakekit fonctionne depuis n'importe quel dossier PowerShell — il n'y a aucun emplacement imposé pour les .glb. Ce qui compte, c'est le chemin donné en argument :

# fichier dans le dossier courant
bakekit chair.glb --auto-light

# chemin relatif
bakekit ..\assets\chair.glb --auto-light

# chemin absolu (guillemets si espaces)
bakekit "C:\Projets\DreamDesk\assets\chair.glb" --auto-light
📂 Par défaut, les textures sortent dans un dossier out créé à côté du fichier d'entrée (pas dans le dossier courant). Utilise --out "chemin" pour choisir une autre destination.

💡 Options essentielles --flag

OptionRôle
--passcombined | diffuse | ao (répétable, défaut : combined)
--resrésolution carrée (défaut 1024)
--samplesqualité Cycles (défaut 256)
--outdossier de sortie

--blenderchemin vers blender.exe si non détecté

☀️ Choisir l'éclairage

Une seule source à la fois — la première trouvée dans cet ordre gagne :

--lights scene.json   # lumières exportées d'une scène Three.js
--auto-light          # rig automatique calculé sur le mesh
--hdri env.hdr         # environnement image
--sun "45,60,3"        # azimut, élévation, intensité

Sinon : les lumières déjà présentes dans le GLB.

💡 Un décalage de luminosité par rapport au rendu Three.js temps réel ? Ajuste --light-scale (les positions/ombres, elles, sont exactes).

📦 Les 3 passes

PasseContenuUsage Three.js
combinedcouleur + lumière finaleMeshBasicMaterial({map})
diffuselumière seule (EXR, HDR)material.lightMap
aoocclusion ambianteaoMap

🧭 Exemples de commandes

Bake minimal, tout par défaut (passe combined, 1024², lumières du GLB) :

bakekit chair.glb

Les 3 passes, en haute résolution, dans un dossier choisi :

bakekit chair.glb --pass combined --pass diffuse --pass ao --res 2048 --out ./textures

Rig automatique quand le mesh n'a pas de lumière (pratique pour un asset isolé) :

bakekit chair.glb --auto-light

Éclairage HDRI, environnement extérieur :

bakekit chair.glb --hdri env/studio.hdr --res 1024 --samples 128

Soleil unique (azimut, élévation, intensité) :

bakekit chair.glb --sun "45,60,3"

Depuis une scène Three.js (fichier généré par dumpThreeLights), avec calibration d'intensité :

bakekit chair.glb --lights scene-lights.json --light-scale 1.4

Un seul objet de la scène, avec un Blender non détecté automatiquement :

bakekit scene.glb --object Chaise --blender "C:\Blender\blender.exe"

Test rapide à basse résolution pour vérifier le rendu avant un bake final :

bakekit chair.glb --res 128 --samples 32
